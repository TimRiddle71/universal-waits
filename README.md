# 🎢 Universal Waits

A simple, mobile-friendly Universal Orlando wait-time dashboard built for quick glances while in the parks.

👉 **[Open Universal Waits](https://timriddle71.github.io/universal-waits/)**

## ✨ Features

- Live attraction wait times
- Separate tabs for **Universal Studios Florida (USF)** and **Islands of Adventure (IOA)**
- Favorite attractions displayed at the top
- Color-coded wait indicators for quick scanning
- Shows when each attraction was last updated
- Manual refresh button
- Designed specifically for an iPhone screen
- Can be added directly to the iPhone Home Screen
- Custom Home Screen icon

## 📱 Add to iPhone Home Screen

1. Open Universal Waits in **Safari**
2. Tap the **Share** button
3. Select **Add to Home Screen**
4. Tap **Add**

Universal Waits will then appear on the Home Screen with its own icon and launch like a small web app.

## 🪄 Why I Built It

The official Universal Orlando app has a ton of useful information, but sometimes I just want one thing:

**How long are the waits for the rides I actually care about?**

Universal Waits gives me that answer immediately without digging through menus or maps.

Built for my Universal Orlando trips.

## 📡 Wait-Time Data

Live attraction information is provided using data from [ThemeParks.wiki](https://themeparks.wiki/).
